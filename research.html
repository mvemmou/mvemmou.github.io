Elastic Miss-Handling for Heterogeneous Memory Systems — MORIA

MICRO '26 ▸
MORIA: Mining the Cache for Miss Parallelism
Marina Vemmou, Alexandros Daglis — 59th IEEE/ACM International Symposium on Microarchitecture (MICRO), 2026

Statically sized MSHRs can't adapt to runtime memory-level parallelism demands, so exhausting them stalls the cache and blocks the pipeline — even while in-cache storage often sits underused. This work repurposes that idle storage into additional miss-handling capacity on demand, adapting to MLP requirements without dedicated hardware, for an average 1.14× speedup and up to 1.98× for individual applications.

Eliminating Network-Induced Memory Bandwidth Waste — Sweeper

MICRO '22 ▸
Patching up Network Data Leaks with Sweeper
Marina Vemmou, Albert Cho, Alexandros Daglis — 55th IEEE/ACM International Symposium on Microarchitecture (MICRO), 2022

Network buffers placed via DDIO look identical to live data once they're in the last-level cache, so the system writes them back to memory even after the application is done with them — wasting bandwidth it can't get back. Sweeper pairs a software API for declaring buffer retirement with a hardware cache-line invalidation instruction that discards consumed buffers without a writeback or any change to the memory consistency model, boosting throughput by up to 2.6×.

High-Throughput Synchronous Persistence — COSPlay

MICRO '21 ▸
COSPlay: Leveraging Task-Level Parallelism for High-Throughput Synchronous Persistence
Marina Vemmou, Alexandros Daglis — 54th IEEE/ACM International Symposium on Microarchitecture (MICRO), 2021
High-Throughput Persistence with Coroutines
Marina Vemmou, Alexandros Daglis — 3rd Young Architect Workshop (YArch) @ ASPLOS, 2021

Crash-consistent applications on persistent memory conservatively serialize persist operations, putting PM latency squarely on the critical path — even though independent tasks often have separate persist contexts that software knows about but has no way to expose to hardware. COSPlay is a three-layer co-design: a coroutine runtime that switches tasks at persist barriers, interface primitives that convey task associations to hardware, and targeted CPU changes that overlap persists across independent tasks while keeping intra-task ordering intact — up to 7.3× higher throughput for high-persist-latency workloads.
